# v1.9.4 Blacksmith release exception

Scope: **v1.9.4 only**. This runbook is a one-time, amd64-only manual exception for
the immutable `v1.9.4` Control Panel and Host Agent release. It must not be copied
to another version, architecture, repository, workflow, or commit.

The `v1.9.4` artifact attestations identify the runner as `self-hosted` because the
release was built and attested on Blacksmith. The normal install guides and the
automatic updater require the attestation-issuing publication job to be
GitHub-hosted and must continue to reject this release. This exception therefore
means that the approving operator accepts the Blacksmith builder for these exact
two artifacts. Pinning the tag, workflow, commit, release record, and digests
prevents this exception from silently expanding, but it does not make a
self-hosted builder equivalent to a GitHub-hosted builder.

do not accept another attestation merely because it belongs to the same
repository.

## Operator-side verification

Run this on an authenticated operator machine with a current GitHub CLI, `jq`,
and `sha256sum`. Use a new empty directory so an older download cannot be reused.

```bash
set -euo pipefail
umask 077

readonly REPO='Kome-Lab/Autostream-ControlPanel'
readonly VERSION='v1.9.4'
readonly COMMIT='d13a3c45aa000ba941eb4c94ee9eb35326151300'
readonly PANEL_ASSET='autostream-control-panel_v1.9.4_linux_amd64.tar.gz'
readonly PANEL_SHA256='44cc5829d882e19f2096772e827dda0d52b851625be9aa4254429df3aa430ae8'
readonly AGENT_ASSET='autostream-host-agent_v1.9.4_linux_amd64.tar.gz'
readonly AGENT_SHA256='5766a06bc8763692588c7330af667c9e5095da4d79b9078921f4045e3ed41987'

test "$(gh api "repos/$REPO/commits/$VERSION" --jq .sha)" = "$COMMIT"
test "$(gh release view "$VERSION" --repo "$REPO" --json isDraft --jq .isDraft)" = 'false'
test "$(gh release view "$VERSION" --repo "$REPO" --json isPrerelease --jq .isPrerelease)" = 'false'
test "$(gh release view "$VERSION" --repo "$REPO" --json isImmutable --jq .isImmutable)" = 'true'
test "$(gh release view "$VERSION" --repo "$REPO" --json targetCommitish --jq .targetCommitish)" = "$COMMIT"

gh release verify "$VERSION" --repo "$REPO"

gh release download "$VERSION" \
  --repo "$REPO" \
  --pattern "$PANEL_ASSET" \
  --pattern "$PANEL_ASSET.sha256" \
  --pattern "$AGENT_ASSET" \
  --pattern "$AGENT_ASSET.sha256"

for asset in "$PANEL_ASSET" "$AGENT_ASSET"; do
  gh release verify-asset "$VERSION" "$asset" --repo "$REPO"
  gh release verify-asset "$VERSION" "$asset.sha256" --repo "$REPO"
done

printf '%s  %s\n' "$PANEL_SHA256" "$PANEL_ASSET" | sha256sum --check --strict
printf '%s  %s\n' "$AGENT_SHA256" "$AGENT_ASSET" | sha256sum --check --strict
sha256sum --check --strict "$PANEL_ASSET.sha256"
sha256sum --check --strict "$AGENT_ASSET.sha256"
```

Verify the artifact provenance with the exact commit and tag. The normal
`--deny-self-hosted-runners` flag is intentionally not used inside this one
exception because it is known to reject these two attestations. Every other
identity constraint remains mandatory.

```bash
set -euo pipefail

verify_v194_provenance() {
  local asset="$1"
  local sha256="$2"
  local evidence="${asset}.attestation.json"
  local repo='Kome-Lab/Autostream-ControlPanel'
  local version='v1.9.4'
  local commit='d13a3c45aa000ba941eb4c94ee9eb35326151300'

  gh attestation verify "$asset" \
    --repo "$repo" \
    --signer-workflow "$repo/.github/workflows/release-host.yml" \
    --signer-digest "$commit" \
    --source-ref "refs/tags/$version" \
    --source-digest "$commit" \
    --predicate-type https://slsa.dev/provenance/v1 \
    --cert-oidc-issuer https://token.actions.githubusercontent.com \
    --format json > "$evidence"

  jq -e \
    --arg asset "$asset" \
    --arg sha256 "$sha256" \
    --arg commit "$commit" \
    --arg ref "refs/tags/$version" \
    '
      length == 1 and
      .[0].verificationResult.signature.certificate.runnerEnvironment == "self-hosted" and
      .[0].verificationResult.signature.certificate.githubWorkflowSHA == $commit and
      .[0].verificationResult.signature.certificate.githubWorkflowRef == $ref and
      .[0].verificationResult.signature.certificate.sourceRepositoryDigest == $commit and
      .[0].verificationResult.signature.certificate.sourceRepositoryRef == $ref and
      .[0].verificationResult.statement.predicate.buildDefinition.internalParameters.github.runner_environment == "self-hosted" and
      any(.[0].verificationResult.statement.subject[];
        .name == $asset and .digest.sha256 == $sha256)
    ' "$evidence" > /dev/null
}

verify_v194_provenance \
  'autostream-control-panel_v1.9.4_linux_amd64.tar.gz' \
  '44cc5829d882e19f2096772e827dda0d52b851625be9aa4254429df3aa430ae8'
verify_v194_provenance \
  'autostream-host-agent_v1.9.4_linux_amd64.tar.gz' \
  '5766a06bc8763692588c7330af667c9e5095da4d79b9078921f4045e3ed41987'
```

Retain the command transcript and both `*.attestation.json` files with the
change record. Record the approving operator, UTC time, destination host, old
versions, and final health checks. Transfer only the two verified `.tar.gz`
files to the server; do not rebuild, recompress, rename, or edit them.

## Update the existing Control Panel

Copy the verified Panel archive to `/tmp` on the server, then run:

```bash
set -euo pipefail
umask 077

require_root_owned_directory() {
  local path="$1"
  local canonical=''
  local unsafe=''

  sudo test -d "$path"
  sudo test ! -L "$path"
  canonical="$(sudo readlink -e -- "$path")"
  if [[ "$canonical" != "$path" ]]; then
    echo "Untrusted release parent path: $path" >&2
    exit 1
  fi
  unsafe="$(
    sudo find "$path" -maxdepth 0 \
      \( ! -user root -o ! -group root -o -perm /022 \) \
      -print -quit
  )"
  if [[ -n "$unsafe" ]]; then
    echo "Release parent is not root:root and non-writable: $path" >&2
    exit 1
  fi
}

ensure_root_owned_directory() {
  local path="$1"

  if sudo test -L "$path"; then
    echo "Refusing a symlink release parent: $path" >&2
    exit 1
  fi
  if sudo test -e "$path"; then
    require_root_owned_directory "$path"
    return
  fi
  sudo install -d -o root -g root -m 0755 -- "$path"
  require_root_owned_directory "$path"
}

require_root_owned_directory /opt
ensure_root_owned_directory /opt/autostream
ensure_root_owned_directory /opt/autostream/releases
ensure_root_owned_directory /opt/autostream/releases/artifacts

sudo install -o root -g root -m 0644 \
  /tmp/autostream-control-panel_v1.9.4_linux_amd64.tar.gz \
  /opt/autostream/releases/artifacts/

printf '%s  %s\n' \
  '44cc5829d882e19f2096772e827dda0d52b851625be9aa4254429df3aa430ae8' \
  '/opt/autostream/releases/artifacts/autostream-control-panel_v1.9.4_linux_amd64.tar.gz' |
  sha256sum --check --strict -

sudo test ! -e /opt/autostream/releases/artifacts/autostream-control-panel_v1.9.4_linux_amd64
sudo test ! -L /opt/autostream/releases/artifacts/autostream-control-panel_v1.9.4_linux_amd64
sudo tar --no-same-owner --no-same-permissions \
  -C /opt/autostream/releases/artifacts \
  -xzf /opt/autostream/releases/artifacts/autostream-control-panel_v1.9.4_linux_amd64.tar.gz
sudo test -d /opt/autostream/releases/artifacts/autostream-control-panel_v1.9.4_linux_amd64
sudo test ! -L /opt/autostream/releases/artifacts/autostream-control-panel_v1.9.4_linux_amd64
unsafe_tree="$(
  sudo find \
    /opt/autostream/releases/artifacts/autostream-control-panel_v1.9.4_linux_amd64 \
    \( ! -user root -o ! -group root -o -perm /022 \) -print -quit
)"
if [[ -n "${unsafe_tree}" ]]; then
  echo 'Control Panel extraction is not an immutable root-owned tree.' >&2
  exit 1
fi
sudo /opt/autostream/releases/artifacts/autostream-control-panel_v1.9.4_linux_amd64/install-autostream-control-panel
```

The fixed extraction directory must not already exist, including as a dangling
symlink. If this guard fails, stop and inspect the retained directory; do not
overwrite or delete it as part of this update attempt.

## Future releases

This exception changes no persistent verifier policy. The automatic updater
remains fail-closed for `v1.9.4`, and the default install guides continue to use
`--deny-self-hosted-runners`.

Control Panel CI and the expensive production artifact build use
`blacksmith-16vcpu-ubuntu-2404`. The build job's first workflow step requires a
`self-hosted` runner. The lighter publication/attestation job uses
`ubuntu-24.04` and first requires `runner.environment == github-hosted` before
downloading or publishing anything. This keeps build and integration-test work
on Blacksmith while separating the write and OIDC permissions onto the
GitHub-hosted publication gate.

For every later release, both amd64 archives must pass the normal verification
command with `--deny-self-hosted-runners`; this runbook must never be reused.
That flag proves that the **attestation issuer** was not self-hosted. It does not
prove that compilation was GitHub-hosted: Blacksmith remains an explicit trusted
build boundary, and the publication job rechecks the transferred artifact set
and fixed digests before issuing attestations and publishing the immutable
release.
